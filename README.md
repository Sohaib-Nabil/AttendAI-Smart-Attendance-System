## Project Overview

AttendAI is an integrated attendance management system that combines a mobile application with an admin/desktop control system.

The system helps organizations manage employee attendance and departure records through a secure mobile-based workflow. Each employee device is linked and verified using a registered device identifier on the server, which helps reduce fake attendance attempts and improves record accuracy.

The platform uses real-time data synchronization to keep attendance records updated instantly between the employee mobile app and the admin system.

---

## Main Features

* Mobile-based attendance and departure registration
* Admin/desktop control system for managing employees and records
* Registered-device verification to prevent attendance from unauthorized phones
* Real-time synchronization using Firebase
* Online and offline attendance support
* Employee management
* Attendance and departure reports
* Excel report export
* Schedule and permission management
* Anti-fraud attendance controls
* Option to disable camera-based attendance when needed
* Secure and practical workflow for small teams and organizations

---

## Problem Solved

Many small organizations still depend on manual attendance records, shared devices, or weak attendance tracking methods. This can lead to inaccurate records, fake attendance attempts, and extra manual work for HR or management.

AttendAI helps solve this problem by providing a controlled mobile attendance system linked to each employee’s registered device, supported by real-time cloud synchronization and admin reporting tools.
